# 📚 Kalender

大学生活を1つの画面で管理するWebアプリです。
授業・出席・予定・やること・習慣・家計簿をまとめて記録でき、AIが今日の献立も提案します。

**▶ 使ってみる：<https://kamiwataru92-lgtm.github.io/Kalender/>**
（スマホのブラウザでも使えます。Googleでログインすると、スマホとPCでデータが同期されます）

---

## なぜ作ったか

<!-- ✏️ ここは自分の言葉に書き直してください -->
大学生活では、授業の時間割、出席回数、課題や予定、バイト代や食費の管理がバラバラのアプリやメモに散らばっていました。
「今日は何の授業があって、あと何回休めるのか」「今月あといくら使えるのか」を、毎朝ひと目で確認できる場所が欲しくて作りました。

## できること

| タブ | 機能 |
| --- | --- |
| 🏠 生活 | 今日のまとめ、やることリスト（前日までの残りも表示）、習慣の記録と連続日数、**AI献立提案** |
| 📝 予定 | 日ごとの予定と、これからの予定の一覧 |
| 🎓 授業 | 時間割の登録、その日の授業の表示、授業ごとの出席記録と累計出席率 |
| 💴 家計簿 | 収入・支出の記録、カテゴリ別の内訳、月の予算と残り |

### 🍳 AI献立提案

「筋トレ中」「揚げ物が食べたい」などの気分と、苦手な食べ物を入れると、AI（Gemini）が一人暮らしでも作れる献立を3つ提案します。
苦手な食べ物は端末に保存され、次回から入力不要です。

## しくみ

```
ブラウザ（GitHub Pages）
 ├─ 画面・記録：HTML / CSS / JavaScript（localStorage に保存）
 ├─ ログイン・同期：Firebase Authentication + Cloud Firestore
 └─ AI献立提案 ──▶ Vercel のサーバーレス関数（api/menu.js）──▶ Gemini API
```

| 使った技術 | 役割 |
| --- | --- |
| HTML / CSS / JavaScript | 画面と記録のしくみ（フレームワークなし） |
| localStorage | ログインしなくても、端末だけで使えるように保存 |
| Firebase Authentication | Googleアカウントでのログイン |
| Cloud Firestore | スマホとPCのデータ同期（オフライン中の変更もあとで送信） |
| Vercel（サーバーレス関数） | AIのAPIキーを隠して、Gemini を呼び出すサーバー |
| Gemini API | 献立の提案 |
| GitHub Pages | アプリの公開 |

## 工夫したこと

### APIキーをブラウザに置かない
AIのAPIキーをブラウザ側のコードに書くと、誰でも見て勝手に使えてしまいます。
そこで、キーは Vercel のサーバー側（環境変数）にだけ置き、ブラウザはサーバー経由で AI を呼ぶ構成にしました。

### ログインした本人だけが AI を使える
サーバーは、Firebase が発行する「ログインした本人の証明（IDトークン）」を検証し、正しいときだけ AI を呼びます。
さらに、このアプリのサイト以外からの呼び出しを拒否し、入力の長さにも上限をつけて、使いすぎを防いでいます。

### 自分のデータは自分だけが読める
Firestore のセキュリティルールで、ログインした本人だけが自分のデータを読み書きできるようにしています（[`firestore.rules`](firestore.rules)）。

### ログインしなくても使える
同期はおまけ機能として作り、ログインしなくても端末だけで全機能を使えるようにしました。
はじめてログインしたときに、端末とクラウドのどちらのデータを使うか選べるようにして、データが消えないようにしています。
